# Malek Finance

**مالك فاينانس — أموالك تحت سيطرتك، بصوتك فقط.**

An independent Android personal finance manager focused on Arabic-first voice entry, clear transaction review, and privacy-conscious local storage.

## Project direction

- Native Android application using Kotlin and Jetpack Compose.
- Offline-first transaction storage with Room.
- Arabic right-to-left interface.
- Voice-assisted income and expense entry with confirmation before saving ambiguous entries.
- Yemeni rial (YER) as the initial default currency, with support designed for additional currencies.
- Minimum Android version: Android 6.0 (API 23), subject to dependency compatibility checks.

## Development

The application is being built incrementally. Each milestone must compile and be tested before it is considered complete. Speech recognition availability depends on the device's installed recognition services and may require network access.
