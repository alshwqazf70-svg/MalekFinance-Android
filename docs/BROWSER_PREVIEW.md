# معاينة التصميم عبر المتصفح

## الغرض
بناء مرجع تفاعلي لمراجعة الهوية والتخطيط والتنقل قبل تكرار بناء وتنزيل APK. تقع المعاينة في `web-preview/` وهي Vite + JavaScript + CSS، بخط Tajawal محلي من حزمة npm، دون خطوط أو خدمات AI خارجية وقت الاستخدام.

**هذه ليست نسخة Android تعمل في المتصفح، ولا محاكي Android، ولا ترجمة لواجهات Compose.** تستلهم نفس الألوان والأقسام والمكونات، مع تخطيط موسّع للحاسوب ووضع هاتف للمراجعة. مصدر Android يبقى `app/`؛ أي تعديل تصميم يُعتمد في المعاينة يجب تطبيقه على Compose واختباره بشكل مستقل.

## التشغيل
يتطلب Node.js 22 أو إصداراً متوافقاً مع Vite 6:

```sh
cd web-preview
npm ci
npm run dev
```

الخادم يرتبط بـ `0.0.0.0:5174` ويسمح بنطاقات معاينة Arena `.e2b.app`. افتح نافذة Live Preview، وليس localhost على هاتفك. جميع موارد المتصفح وروابطه نسبية؛ لا يوجد backend ولا اتصال ببيانات Android. تعديل ملفات المعاينة يحدّث العرض عبر Vite HMR.

```sh
npm test          # 13 اختباراً لنواة المعاينة
npm run build    # بناء الويب فقط؛ ليس APK
```

اختبارات المتصفح:

```sh
npx playwright install chromium
npm run test:e2e
```

يمكن استخدام Chromium مثبت مسبقاً عبر `CHROMIUM_EXECUTABLE_PATH`. اختبارات Playwright تشغّل/تعيد استخدام خادم التطوير محلياً. يلزم تثبيت متطلبات Chromium المناسبة لنظام التشغيل؛ حزمة المتصفح ليست جزءاً من المستودع.

## ما يمكن تجربته فعلياً
- خمس شاشات: الرئيسية، العمليات، المساعد، التقارير، مالي.
- تخطيط RTL متجاوب، وضع هاتف اختياري، ألوان النظام الجديد، وإخفاء المبالغ.
- بيانات توضيحية أولية موسومة بوضوح، مع إمكانية إعادة الأمثلة أو بدء مساحة فارغة.
- إضافة عمليات دخل/مصروف تجريبية بعد مراجعة نموذج التأكيد، وحذفها والبحث والتصفية.
- محافظ مستقلة YER / USD / SAR / AED، وأرصدة محسوبة من الافتتاحي والعمليات والتحويلات باستخدام BigInt.
- تحويلات تجريبية بين محافظ العملة نفسها مع فحص الرصيد وعدم احتسابها دخلاً أو مصروفاً.
- تقارير للفترة المختارة، مخطط آخر سبعة أيام، تصنيف أعلى إنفاقاً، وسيناريو توفير توضيحي.
- محلل نصي مبسط بالمتصفح: مبلغ واحد بأرقام عربية/فارسية/لاتينية وعبارات دخل/مصروف محدودة، ثم مسودة قابلة للتعديل. ليس VoiceTransactionParser الأصلي، ولا يدعم كل صيغ الأعداد المنطوقة.

## ما ليس مفعلاً هنا
- **لا ميكروفون أو تعرف صوتي.** لا نستخدم Web Speech API أو fallback سحابياً. تكامل واجهة التعرف المثبتة على الهاتف يحتاج Android، ولا يوجد Vosk أو نموذج مضمّن حاليًا.
- الميزانيات والادخار والفواتير أمثلة تصميم موسومة، لا إدارة كاملة أو دفع أو حجز ادخار من أرصدة المعاينة.
- لا Room، أو واجهة تعرف الهاتف، أو تذكيرات فعلية، أو نسخ احتياطي مشفر، أو تصدير ملفات Android.
- لا مصادقة أو ربط بنكي أو مزامنة بيانات أو اعتماد سلامة/أداء APK.

## البيانات والخصوصية
بيانات البداية أمثلة وليست أرقام المستخدم. تُحفظ تغييرات المعاينة في `localStorage` تحت المفتاح `mk-finance-design-sandbox-v1`، في المتصفح/الأصل نفسه فقط، دون تشفير. لا تدخل معلومات مالية حقيقية. إذا حُظر التخزين، تعمل الجلسة في الذاكرة ويظهر ذلك في الشريط؛ لا يمكن ضمان بقاء التغييرات بعد إغلاق الصفحة.

لا تتغير قاعدة Android أو بيانات الهاتف بأي إجراء هنا. إعادة الأمثلة أو إفراغ البيانات تحتاج تأكيداً. النصوص المضافة تُعرض بعد HTML escaping، والمبالغ بوحدات صحيحة لا floating point. بيانات التخزين تُراجع بنيوياً قبل استخدامها. وضع إخفاء المبالغ إجراء بصري، وليس قفلاً أمنياً.

## سير المراجعة
1. شاهد الرئيسية في حجم الهاتف والحاسوب.
2. تنقل بين الشاشات وجرّب عملية ومحفظة وتحويلاً.
3. أرسل في المحادثة اسم الشاشة والتغيير المطلوب أو لقطة للعنصر.
4. نعدّل المعاينة ونراجعها دون APK لكل تعديل.
5. بعد اعتماد الاتجاه نطبّقه على Android، ثم نبني APK للتحقق الحقيقي من Compose والصوت والبيانات والأذونات.

## التحقق في هذه الدفعة — 2026-11-25

- نجاح `npm run test:e2e`: 7 اختبارات Chromium للتنقل المتجاوب، مراجعة الحفظ واستمراره، البحث، الخصوصية، المساعد النصي دون ميكروفون، المحافظ والتحويلات ورفض نقص الرصيد، وعرض النص غير الموثوق بأمان.
- نجاح بناء Vite، ومعاينة فعلية في Chromium بعرض 1440 و390 بكسل دون تجاوز أفقي في الشاشات المختبرة.
- هذه النتائج تخص معاينة الويب فقط، ولا تغيّر حالة اعتماد Android أو المحرك الصوتي.

## انتهاء الرابط المؤقت وبديل الملف المستقل
روابط بيئة Arena/E2B مؤقتة. قد يظهر `502 / Sandbox not found` حتى لو استجاب الخادم داخل جلسة العمل؛ فحص localhost وحده لا يثبت أن المدخل الخارجي قابل للوصول. لا نعد رابطاً يدوياً ثابتاً، ولا يُصلَح خطأ عدم العثور على البيئة بتغيير واجهة التطبيق. أعد فتح نافذة Live Preview الحالية؛ إذا استمر الخطأ فقد يلزم استئناف/إعادة فتح بيئة العمل من المنصة.

يتوفر تصدير مستقل لا يعتمد على خادم المعاينة:

```sh
cd web-preview
npm run export:standalone
```

الناتج `exports/MK-Finance-preview.html` يضم JavaScript وCSS والخطوط والأيقونة داخله. نزّله وافتحه بمتصفح يدعم تشغيل ملفات HTML المحلية. ليس APK ولا يحتاج تثبيت Android؛ حدوده وبياناته التجريبية كما في نسخة الويب، ولا يتضمن الصوت. بعض عارضات الملفات على الهاتف تمنع JavaScript؛ استخدم متصفحاً مناسباً بدلاً من عارض الملفات عندئذ.

ملفات التصدير مولّدة ومُستثناة من Git، وتحتاج إعادة توليد عند تعديل التصميم؛ الملف المحمّل لا يتحدث تلقائياً. يعتمد دعم localStorage للملفات المحلية على المتصفح؛ إن حُظر التخزين تبقى التجربة في الذاكرة فقط.

تم فحص الملف في Chromium مع تعطيل الشبكة: فتح عبر `file://`، تنقل هاتف، إضافة مبلغ عربي والبحث عنه، دون طلبات HTTP أو أخطاء JavaScript. لا يعني ذلك ضمان التشغيل في كل عارض HTML على الهواتف.

## الوصول للكود من داخل صفحة المعاينة
المنفذ الافتراضي الحالي **5174** في إعدادات Vite وأوامر التشغيل واختبارات المتصفح. أضيف رابط ظاهر «فتح الكود وملفات التنزيل» داخل المعاينة عبر HTTP/HTTPS، يقود إلى `/preview-files/`. تتيح الصفحة قراءة JavaScript وCSS والحسابات كنص مباشر دون تنزيل، وتنزيل HTML/ZIP بروابط ويب عادية مع ترويسة Content-Disposition الصحيحة؛ لا تستخدم مخطط `sandbox:` الخاص بالمرفقات. لا يظهر الرابط في الملف المستقل المفتوح عبر file://.

لتجهيز ملف HTML وحزمة الكود معاً، شغّل `npm run export:bundle` (يتطلب Python 3 للحزمة فقط). مسارات الملفات ثابتة ومحددة صراحة في خادم التطوير؛ لا تسمح بقراءة مسار اختياري من المستودع. إذا لم توجد الصادرات ترجع روابط تنزيلها 404 برسالة واضحة، بينما تبقى قراءة الكود متاحة. هذه المسارات لخادم Vite التطويري فقط، وليست مضمّنة كخدمات في بناء static أو في APK.

نجح اختبار متصفح إضافي لفتح صفحة الملفات وقراءة الكود وتنزيل ZIP من نفس أصل المعاينة. هذا يثبت مسار HTTP الداخلي والمتصفح الاختباري، ولا يثبت أن منصة الاستضافة الخارجية قابلة للوصول من هاتف المستخدم؛ خطأ Sandbox not found يبقى متعلقاً بمدخل البيئة.
